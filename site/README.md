Sistema Interno - Chácaras Moura

A Chácaras Moura é uma empresa especializada na venda de mini chácaras para quem busca o equilíbrio perfeito entre natureza e conforto. Localizada em uma área privilegiada, oferece terrenos amplos, ideais para moradia longe do agito urbano, mas com toda a comodidade necessária. Com mini chácaras que possuem vista para uma natureza exuberante, a empresa proporciona qualidade de vida, tranquilidade e um atendimento personalizado, facilitando a realização do sonho da casa de campo.

Este repositório contém o sistema interno da empresa, utilizado para o controle de lotes vendidos. A plataforma permite acompanhar a situação de cada mini chácara (disponível, reservada ou vendida), auxiliando a equipe interna na gestão do empreendimento.

🔗 Acesse a versão publicada do sistema: https://www.chacarasmoura.com.br/

🎯 Objetivo do Projeto

Disponibilizar uma ferramenta interna, simples e de fácil navegação, para que a equipe da Chácaras Moura possa:

Visualizar o status de cada lote/mini chácara do empreendimento (disponível, reservado ou vendido);
Manter um controle organizado das vendas realizadas;
Acompanhar informações relacionadas aos lotes e clientes de forma centralizada;
Facilitar a gestão interna do loteamento, evitando erros de venda duplicada ou desatualização de status.
📁 Organização do Projeto

O repositório é organizado da seguinte forma:

site-chacaraMoura/
└── site/          # Código-fonte do site (páginas, estilos, scripts e assets)

Todo o código da aplicação está concentrado dentro da pasta site, mantendo a raiz do repositório limpa e dedicada apenas à organização geral do projeto.

🛠️ Tecnologias Utilizadas
HTML5 — Estruturação das páginas.
CSS3 — Estilização e responsividade do layout.
JavaScript — Interatividade da página.
Vercel — Plataforma utilizada para hospedagem e deploy contínuo do site.

Caso o projeto utilize algum framework ou biblioteca adicional (como React, Vite, Bootstrap, etc.), atualize esta seção para refletir com precisão as tecnologias empregadas.

🚀 Como Executar o Projeto Localmente
Pré-requisitos
Um navegador web atualizado.
Git instalado (para clonar o repositório).
Opcionalmente, uma extensão como o Live Server (VS Code) para servir o site localmente.
Passos
Clone o repositório:
bash
git clone https://github.com/lucasMunizt/site-chacaraMoura.git
Entre na pasta do projeto:
bash
cd site-chacaraMoura/site
Abra o arquivo index.html diretamente no navegador ou utilize uma extensão de servidor local (como o Live Server) para visualizar o site com recarregamento automático.
🌐 Deploy

O projeto está hospedado na Vercel, sendo atualizado automaticamente a cada novo push realizado na branch principal do repositório.
